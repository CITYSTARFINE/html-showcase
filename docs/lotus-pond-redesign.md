# 荷塘月色 · 水墨青绿重绘

制作工具：**Codex**；使用技能：[html-showcase](../skills/html-showcase/SKILL.md)。该文档对应由该技能指导制作/重绘的最终展示作品。

交付文件为 `index.html`，可直接在浏览器打开，无需构建。three.js 与 addons 使用 importmap 锁定 0.160.0，首次加载需要联网。CSS、业务 JS、模型、纹理与环境音全部内联或程序化生成；字体使用本地楷体/宋体回退。原始文件另存于仓库的 `archive/lotus-pond-v7.html`，未覆盖。

## 改动说明

| 项目 | 改了什么 | 为什么 |
| --- | --- | --- |
| 色彩 | 青绿减彩度，浅色天空和雾用月白、灰绿，夜景改青冥；荷花用暖白与灰粉，锦鲤红斑改朱砂。 | 统一水墨青绿气质，避免鲜绿、亮橙彼此争抢。 |
| 光影 | 日光与月光方向插值；增加独立日轮 sprite，月轮在首幕可见；降低光柱、光尘的强度，调整柔影偏移与承影强度。 | 日景以晨雾和透光为主，夜景以月光与流萤为锚点，形成不同情绪。光柱仍为透明交叉面近似体积感，并非物理体积散射。 |
| 构图 | 二十七片荷叶确定性排布，前景框景、中景花簇、远山留白；调整五个机位的高度与观察目标。 | 避免每次刷新随机拥挤，增加近实远虚与疏密关系。 |
| 材质 | 叶片径向细分、收窄缺口、保留杯状与边缘波浪，增加蜡质高光；花瓣改弯曲薄片与规范 UV，增加单次着色的逆光透亮近似；反射扰动从 0.9 收到 0.20。 | 使荷叶与花瓣具有曲面质感，保留清晰倒影。鱼在透明水面后绘制，仍接受荷叶深度遮挡，避免被承影面完全挡住。 |
| 雾气 | 保留 55–165 线性雾，水面远处混入昼夜雾色；调整水雾、夜雾的透明度与呼吸周期。 | 水面、贴水雾、远山分层，夜雾不把整个画面洗成白色。 |
| 动效 | 三层波浪减幅、放缓；流萤闪烁和雾气呼吸放慢；鱼用连续相位避免疾游时瞬间跳位，受惊移动限速 4.5、位移限幅 5；拖动加入惯性衰减。 | 降低碎乱感，同时保留全部交互触发。 |
| UI | 保留原布局，使用本地楷体、细框宣纸按钮、印泥噪点与朱砂印章；昼夜分别使用墨色/月白文字，给诗句加柔和底衬；圆点改可键盘访问的按钮。 | 提升正文可读性及国风质感，避免印章与标题末字重叠。 |

## 要素保留与源码差异

保留天空穹顶 shader、日月盘与光晕、380 点星空、内外各八段远山、线性雾、Reflector 真反射及假反射降级、三层波浪与十二槽涟漪、叶脉纹理与风倾斜、七朵开放荷花与三朵花苞、鱼的身体/各鳍/眼睛/触须、所有粒子类别、完整后期、真实阴影、昼夜切换和 Web Audio 合成环境音。

原源码与用户清单不同的部分按清单对齐：荷叶由可能跳过的随机生成改为固定 27 片；鱼从 7 条补到 8 条；光尘从 220 粒调整为 40 粒；滚轮上限从 85 改为 60；补独立日轮 sprite、拖动阻尼及任意输入打断导览。保留原相机飞行约 1.9 秒和原点击、导航触发方式。四层 41 个花瓣、20 个花蕊使用实例化绘制，未省略实例。粒子缓冲总数为 862，反射贴图 1024，阴影贴图 2048，pixelRatio 上限 2。

五章诗句、昼夜副文案均逐项对比原文，未改写。

## 自测清单与限制

已在独立 Edge 浏览器验证：

- 五章各自的日间/夜间文案与相机视角；保存十张桌面截图。
- 手机 390 × 844 日夜截图与无横向溢出。
- 点击荷花绽放；点击鱼疾游；指针在水面产生涟漪、水花、泡沫，鱼受惊且位移限幅；空中指针产生风 streaks。
- 拖拽旋转、阻尼、滚轮范围、方向键、上一幕/下一幕、圆点导航。
- 自动导览推进与字幕同步；指针输入退出导览。
- 声音开关后的 AudioContext 运行状态及 audioOn 状态。
- visibilitychange 隐藏/恢复处理（以浏览器内模拟隐藏状态与事件验证计时暂停/恢复）。
- 阻断 Reflector 模块，仍使用假反射；阻断 CDN 且禁用缓存，显示静态摘要、加载器退出。此测试模拟网络请求失败，没有把错误 CDN 地址留在交付物中。
- WebGL2 检测失败、主动触发 WebGL 上下文丢失，均显示有样式的标题与要点摘要。
- 最终内联脚本语法、固定版本、无外部字体/模型/音频文件。

性能记录：1440 × 900、DPR 1 的独立无窗口 Edge 首幕，3 秒采样平均约 199 fps（无窗口环境的 rAF 频率，不代表用户显示器刷新率）。该结果只代表当前测试环境，不保证每个设备、DPR 2 或每个视角都达到 60fps。

未完成主观音色/扬声器听感验收，也未进行全部浏览器、真实手机触控、多设备 GPU 长时间压力测试；不把程序运行状态当作听感验收。未复制用户没有提供的真实实验数据。

## 使用与替换

直接打开 `index.html`。顶部按钮切换导览、章节、昼夜和声音；拖拽环视、滚轮远近，方向键及空格切章。没有外部生图素材。要修改内容，编辑 `SECTIONS`；要调整视觉，编辑开头 CSS、昼夜颜色、花叶纹理函数与 `GradeShader`。替换原版前建议先打开这份重绘版进行主观美术与音效确认。
