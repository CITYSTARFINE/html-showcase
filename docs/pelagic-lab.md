# PELAGIC · 深海生物实验室

原创未来生物实验室概念作品，采用深海蓝、青色辉光与电影感三维光影。内容用于作品集和视觉演示，不对应真实机构、实验设备、技术性能或研究成果。

## 设计

- 悬浮培养舱：玻璃外壳、金属骨架、嵌套有机曲面与扫描光环。
- 分子档案：程序化双螺旋、精密环架和金属梯级。
- 光谱观测台：叠层透镜、镜架与明确标为概念信号的扫描屏。
- 空间：建筑肋架、灯带、地面网格、线性层次与雾；金属反射使用程序化环境贴图。
- 光影：半球光、主方向光、两盏彩色轮廓光、局部青色光、真实阴影和 Bloom。
- UI：中文讲解、英文等宽标签、章节导航、信息面板和可退出导览。

## 技术与交互

单文件 HTML，three.js 和 addons 通过 importmap 锁定 0.170.0。场景使用 1600 粒子、单 rAF 循环、50° 相机、pixelRatio 上限 2。所有模型、纹理与装饰程序生成，没有外部模型、图片、字体或生图 API。

拖动旋转、滚轮或 ＋ / − 缩放；悬停 raycast 节流，高亮并缩放 1.05，显示标签；点击装置查看信息，可点击“靠近观察”；章节切换为 1.6 秒相机飞行，飞行期间禁用重复导航与场景控制。自动导览有字幕，用户输入立即退出。支持电影光影/流畅模式、页面隐藏暂停和 WebGL/CDN 失败摘要。

## 使用与修改

打开 `../projects/pelagic-lab/index.html`。首次加载需联网，文件中所有业务 CSS/JS 已内联。修改配色使用 CSS 变量；仪器说明在 `data`；相机路点在 `points`；材质、灯光和几何都在同一脚本中。

## 验收

已在独立 Edge 检查桌面 1440 × 1000、矮屏 1366 × 768、手机宽度 390 × 844，以及悬停/拾取、旋转缩放、章节飞行锁定、键盘导航、自动导览与退出、减少动态效果、隐藏事件暂停恢复和 CDN/WebGL 失败摘要。

没有保证所有设备达到 60fps，未进行跨浏览器和真实手机长时间测试。
