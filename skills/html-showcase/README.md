# HTML 展示页脚手架

用于课堂展示、产品介绍等替代 PPT 的展示页。`SKILL.md` 是可复用技能入口；模板、预设与脚本都随目录携带。可以在任何工作目录运行 `python 路径/showcase-template/new.py`，新项目生成在运行时的当前目录中，目录名为用途拼音加本地日期；重名自动追加编号，不覆盖旧项目。

## 工作流与铁律

1. 澄清：用户首次提出需求后，按 SKILL.md 的“首次需求选项”主动用原生可点击选项收集未明确的视觉方向、美术完成度、技术等级、展示交互和内容来源；已明确的信息保留，不重复询问。等级由用户亲选，不擅自升级。用户说“随便”：课堂默认 T1，产品默认 T2，明确告知；其他用途继续询问。T3 永不默认，动工前必须用户明确确认。
2. 规划：根据用户材料或授权搜索获得的可靠来源列出章节与每章重点。可自行撰写讲解、组织结构和练习，但不虚构事实；仅对无法检索或验证的必要信息询问用户。模板的“待补充”只是占位，不能冒充最终内容。
3. 构建：运行 `new.py`，选择预设或输入自定义的三个形容词与一个参考。自定义描述写入 HTML 注释，七个变量以极简初值待调整；脚本不凭形容词编造品牌视觉。按照真实参考修改变量后完成内容。
4. 截图验收：在桌面和窄屏检查标题、正文、对比度、溢出及遮挡；验证鼠标、键盘、减少动态效果。T2 检查滚动显现、视差、进度与每章 hero；T3 检查所有交互、背景暂停、CDN/WebGL 失败摘要，并在目标设备测量帧率。发现问题后修复并重新截图。
5. 交付：只交付新项目的 `index.html`。CSS 和业务 JS 已内联，不需要 npm、打包或构建。模板源文件使用相对资源引用供维护；不要把未生成的模板当作单文件交付。

## 技术等级与交互边界

| 等级 | 技术与交互 |
| --- | --- |
| T1 轻量 | 语义化 HTML、CSS 入场动画、零依赖；锚点点击、方向键和空格切章；CSS hover 状态。不得加入滚动叙事、视差或三维。 |
| T2 精美 | IntersectionObserver 滚动显现/转场、视差层、卡片按钮 hover 微交互、平滑导航、阅读进度；每章一个 hero 时刻。最多一个 CDN 动画库，本模板不使用。不得加入 three.js。 |
| T3 极致 | importmap 引入 three.js，锁定 `0.170.0`，禁止 latest；1800 个粒子（必须小于 20000）、单 rAF 循环，目标 60fps，需目标设备实测。 |

风格与等级独立：极简、科技、国风、赛博朋克、扁平插画、暗黑、学术都由 `styles/presets.css` 提供七个核心变量 `--bg/--surface/--accent/--text/--muted/--font-display/--font-body`，另有质感、圆角与辉光变量。国风包括水墨渐变和印章装饰，赛博朋克包括青品霓虹和程序噪点纹理；无外部字体依赖。切换 `html` 的 `data-style` 不会改变等级或交互。

## T3 维护规范

- renderer 开 antialias，pixelRatio 为 `min(devicePixelRatio,2)`；hemisphere、主 directional、两盏彩色 rim；scene fog；相机视角 50°，保持在 45–60°。
- raycast hover 在 pointermove 标记后最多每 50ms 计算一次；悬停 emissive 增强、缩放 1.05、浮标签。点击物体打开信息面板。拖动旋转、滚轮缩放；极角钳制 0.2 到 π−0.2，半径 3–16。
- 导览按相机路点轮流推进，章节字幕同步。任何用户输入立即退出导览；导览按钮自身的启停点击除外。退出不突停正在完成的飞行。章节切换以 1.5 秒 tween 飞行，期间禁用拖动、缩放、拾取和重复导航。
- 2D UI 绝对定位在 canvas 上方，wrapper `pointer-events:none`，按钮和导航 `auto`。飞行时 overlay 淡出，到达淡入；减少动态效果设置关闭装饰旋转、视差和 CSS 动画，但保留规格要求的相机飞行。
- visibilitychange 隐藏时取消 rAF，恢复时修正飞行和导览计时，不重复创建循环。动态 import、初始化和逐帧渲染均有失败处理；WebGL2 检测失败、CDN 失败、上下文丢失均显示有样式的标题与要点摘要，绝不白屏。
- T3 单文件仍需要联网加载固定版本库；离线时提供静态摘要。首次测试建议用 `python -m http.server 8000` 在项目目录启动预览并访问 localhost，这是预览服务，不是构建步骤。T1/T2 可直接打开 HTML。

three.js API 维护参考：[WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)、[Raycaster](https://threejs.org/docs/pages/Raycaster.html)。固定版本升级需明确选版本并重新验证，不得使用浮动地址。

## 文件

`templates/t1.html`、`t2.html`、`t3.html` 分别提供三个等级；`js/nav.js` 共享章节导航，T3 通过事件执行相机飞行；`js/t3-base.js` 提供三维基础交互与降级；`new.py` 只依赖 Python 标准库。所有源码注释和内容占位均为中文。

## 装饰素材生成规范

展示页的装饰类视觉素材（背景纹理、分隔线、插图、hero 配图）默认程序化生成，不调用外部生图 API。

- 使用内联 SVG 制作图案、插图、印章、噪点滤镜；使用 CSS 制作渐变、辉光、扫描线；Canvas 粒子和动态纹理仅用于 T3，并复用其单一渲染循环。静态 SVG/CSS 装饰不改变等级，不得向 T1 加入滚动叙事或向 T1/T2 加入三维、Canvas 动态纹理。
- 按风格选择手法：国风＝水墨渐变、印章 SVG、细框线；科技＝网格线、辉光边、等宽数据标签；赛博朋克＝霓虹渐变、扫描线、噪点 overlay；扁平插画＝几何图形、柔和阴影；暗黑＝暗角、细金线、克制辉光；极简/学术＝留白、发丝线分隔，不添加其他装饰。
- 装饰不得干扰正文可读性。纯装饰 SVG 标记 aria-hidden="true"，装饰层 pointer-events:none；正文保持足够对比度。窄屏隐藏大插图及复杂装饰层，保留底色；在截图验收中检查。具有教学信息的图示属于内容，必须依据用户材料或经核验的可靠来源制作，不可当作装饰隐藏或编造。
- 例外：仅当用户明确要求写实/摄影级配图，并能提供可用的生图 API key 时，才可使用 AI 生图。通过安全的密钥配置使用，绝不把 key 写进 HTML、技能或交付文件。
- 例外图片转为 base64 内联进最终 HTML。每张原始图片及 base64 编码内容均须小于 500KB（保守按 500000 字节检查）；超限先缩放或压缩，再核验清晰度。交付时注明图片来源/生成工具与替换方式；替换对应 img 的 data URL，并保留 alt 文本及尺寸约束。
## 内容获取方式

先问：“内容来源你希望选哪种？① 你提供材料；② 我搜索可靠来源并整理生成；③ 你提供部分材料，我补充搜索。”用户已表达“你自己搜”“没有材料，帮我生成”等授权时直接采用对应方式，无需再要求上传材料；用户选择自行提供且表示稍后提供时，不擅自改为搜索。

- 用户提供：依据所给材料整理；缺少关键内容时询问，或经用户同意保留明确占位。不得无授权补入外部事实。
- 搜索并生成：先确认影响讲解深度的必要信息，例如主题、受众/年级、时长及范围。非必要信息用合理假设并告知；无需等待用户提供课件、教材文件或正文。随后主动检索并打开来源，整理事实，自行编写结构、讲解和练习。
- 两者结合：保留用户材料的语境；对材料之外的内容搜索核验。重要冲突说明来源差异并提出取舍，不静默替换用户材料。
- 搜索优先官方机构、教材出版方、大学、研究论文等权威或一手来源；核实发布日期、适用范围及涉及版本。事实、数值、引用和真实案例需有支持，关键论断在相邻位置给出可点击来源，交付 HTML 保留参考来源。原创问题、说明性类比、假设案例与推断明确区分；不把模拟实验数据当作真实结果。
- “可以生成”表示可以撰写表达和组织内容，不表示可以虚构事实。非公开产品参数、内部业绩、个人经历等无法检索的信息只询问必要部分；无法验证的非必要内容删去、注明不确定或经用户同意占位，不因此阻塞整个项目。
- 无法联网或来源不足时说明限制，继续完成已核实部分，针对缺口询问；不得假装已经搜索。下载并内联网络图片须有合适的使用许可并注明来源；此模式不改变装饰素材默认程序化生成的规定。
- `new.py` 只生成脚手架，不自动联网或生成课程正文；内容获取选择由使用本技能的 Codex 在对话中处理。等级与风格限制始终保持。
## 选项内容与美术要求

以下为选项设计示例，按用户主题与已知选择调整；每次最多三问，不把所有问题一次堆给用户。

| 询问项 | 可点击选项示例与处理 |
| --- | --- |
| 美术完成度 | 精细清晰 / 编辑级视觉 / 最高美术完成度。最高美术完成度不自动等于 T3；同一等级内仍需完善字体层级、构图、留白、内容图示和一致性，不能把原始模板换文字当作成品。 |
| 风格 | 极简 / 科技 / 国风 / 赛博朋克 / 扁平插画 / 暗黑 / 学术；允许自由输入自定义方向。原生工具选项数受限时提供主题相关的 2–3 个方向及自由输入，不丢弃七套预设，必要时在后续轮次展开。 |
| 具体视觉方向 | 围绕主题给 2–3 个有差别的方向。例如学术光合作用：科学杂志编辑版式 / 教材图解版式 / 严谨讲义版式。方向调整构图和内容图示，不改变既选的配色预设或等级。 |
| 技术等级 | T1：零依赖、点击/键盘切章；T2：滚动叙事、视差和微交互；T3：三维场景、相机导览与物体交互。说明能力后让用户亲选，不以“最高美术”暗中升级。选择明确写作“确认 T3”的选项并由用户提交可作为确认；单纯预选无效。 |
| 展示交互 | 只提供与等级兼容的实现：T1 为逐章讲解/锚点自由跳转，T2 为连续滚动叙事/导航引导的章节滚动，T3 为相机路点讲解/三维自由探索。已选交互需要更高等级时解释冲突，询问调整等级或在原等级内替代，不暗中越级。 |
| 内容来源 | 我提供 / 你搜索并生成 / 两者结合。用户已授权搜索则直接搜索，不再要求上传材料。 |

默认装饰程序化生成。最高美术完成度通过精细设计达成：每章有明确的信息焦点，版式避免机械重复，核心关系用有依据的 SVG/CSS 内容图解表达；学术/极简仍遵守不加无意义装饰的规范。截图验收同时检查美术质量，不能只检查代码能运行。

原生按钮属于 Codex 对话界面的偏好收集；`new.py` 是终端问答，不提供聊天按钮。若要更改脚本的提问逻辑，另行修改脚本，不把对话规则写成脚本已有功能。
