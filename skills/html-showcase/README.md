# HTML 展示页脚手架

用于课堂展示、产品介绍等替代 PPT 的展示页。`SKILL.md` 是技能入口；所有模板、预设与 Python 标准库脚本随目录携带。

## 工作流

需求按钮向导（含配色）→ 内容规划 → 2–3 个视觉方向供选择 → 完整视觉方案确认 → 构建 → 截图验收 → 交付。

- intake 由 `new.py` 完成，对话不再重复问。保留已有明确选择，每轮最多三问；T3 必须另次确认，美术完成度不会改变技术等级。
- 用户说“随便”：课堂 T1、产品 T2，明确通知；其他用途须选择。T3 永不默认。
- 完整视觉方案含逐屏前/中/背景构图、3–5 个关键画面、素材负责人/方式/尺寸/来源；T3 再列镜头路径、光照、后处理。用户确认后才允许构建。
- 对标只用真实照片、画作或项目截图；找不到时写“暂无对标”。AI 仅在授权后制作最终素材，不用于效果论证，不需要用户 API key。
- 内容可由用户提供、授权搜索整理或结合；不强制上传，不编造事实。搜索由 Codex 执行并保留来源，脚本不自动联网搜正文或调用 imagegen。
- 验收只给“通过／小修（清单）／返工（原因）”，具体要求见 [references/tiers.md](references/tiers.md)。未测项目如实说明。

## 启动与调整

```text
python 路径/html-showcase/new.py --state intake.json
```

默认打开仅本机可访问的按钮向导。选择不会预提交；逐阶段提交、支持续填，结束后只保存需求，不生成展示页。按 Ctrl+C 结束服务。无法使用浏览器时加 `--cli`（此模式是终端问答，不是按钮）。

Codex 使用原生聊天按钮时，运行 `--questions` 读取脚本问题、记录实际答案，不再另设一套对话 intake。已有选择用 `--known known.json` 预填。状态接口、视觉方案格式与构建命令见 [references/intake.md](references/intake.md)。

需要修改已选需求时，将改动写入 JSON 并用 `--known` 更新状态。改动会使相关确认失效；已批准方案的摘要也必须重新确认。视觉方向选择和完整方案确认在 Codex 对话中完成，不是向导结束自动同意。

构建后新项目目录为用途拼音加本地日期，重名追加编号，不覆盖旧项目。只交付新项目 `index.html`，CSS/业务 JS 内联，无需 npm 或打包。生成模板仍是脚手架，须按确认方案完善后验收，不作为最终美术成品。

## 技术等级与交互边界

| 等级 | 技术与交互 |
| --- | --- |
| T1 轻量 | 语义化 HTML、CSS 入场动画、零依赖；锚点点击、方向键和空格切章；CSS hover 状态。不得加入滚动叙事、视差或三维。 |
| T2 精美 | IntersectionObserver 滚动显现/转场、视差层、卡片按钮 hover 微交互、平滑导航、阅读进度；每章一个 hero 时刻。最多一个 CDN 动画库，本模板不使用。不得加入 three.js。 |
| T3 极致 | importmap 引入 three.js，锁定 `0.170.0`，禁止 latest；1800 个粒子（必须小于 20000）、单 rAF 循环，目标 60fps，需目标设备实测。 |

风格与等级独立：极简、科技、国风、赛博朋克、扁平插画、暗黑、学术都由 `styles/presets.css` 提供七个核心变量 `--bg/--surface/--accent/--text/--muted/--font-display/--font-body`，另有质感、圆角与辉光变量。国风包括水墨渐变和印章装饰，赛博朋克包括青品霓虹和程序噪点纹理；无外部字体依赖。切换 `html` 的 `data-style` 不会改变等级或交互。

## T3 维护规范

- renderer 开 antialias，pixelRatio 为 `min(devicePixelRatio,2)`；hemisphere、主 directional、两盏彩色 rim；scene fog；相机视角 50°，保持在 45–60°。
- raycast hover 在 pointermove 标记后最多每 50ms 计算一次；悬停 emissive 增强、缩放 1.05、浮标签。点击物体打开信息面板。拖动旋转、滚轮缩放；极角钳制 0.2 到 π−0.2，半径 3–16。
- 导览按相机路点轮流推进，章节字幕同步。任何用户输入立即退出导览；导览按钮自身的启停点击除外。退出不突停正在完成的飞行。章节切换以 1.5 秒 tween 飞行，期间禁用拖动、缩放、拾取和重复导航。
- 2D UI 绝对定位在 canvas 上方，wrapper `pointer-events:none`，按钮和导航 `auto`。飞行时 overlay 淡出，到达淡入；减少动态效果设置关闭装饰旋转、视差和 CSS 动画，但保留规格要求的相机飞行。
- visibilitychange 隐藏时取消 rAF，恢复时修正飞行和导览计时，不重复创建循环。动态 import、初始化和逐帧渲染均有失败处理；WebGL2 检测失败、CDN 失败、上下文丢失均显示有样式的标题与要点摘要，绝不白屏。
- T3 单文件仍需要联网加载固定版本库；离线时提供静态摘要。首次测试建议用 `python -m http.server 8000` 在项目目录启动预览并访问 localhost，这是预览服务，不是构建步骤。T1/T2 可直接打开 HTML。

three.js API 维护参考：[WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer.html)、[Raycaster](https://threejs.org/docs/pages/Raycaster.html)。固定版本升级需明确选版本并重新验证，不得使用浮动地址。

## 文件

`templates/t1.html`、`t2.html`、`t3.html` 分别提供三个等级；`js/nav.js` 共享章节导航，T3 通过事件执行相机飞行；`js/t3-base.js` 提供三维基础交互与降级；`new.py` 只依赖 Python 标准库。所有源码注释和内容占位均为中文。

## 学术展示的逻辑组织

论文答辩、课程汇报、学术展示及课堂用途先提炼一句主线，删除跑偏章节；概念关系用流程图/对比表/层级图/时间线表达，每章开头有承上启下句。详见 [references/styles.md](references/styles.md)，不受配色预设限制。陌生真人看完说不出主线则返工；未测列小修待补。

## 配色选择

风格选完后，主动确认颜色：沿用预设／从推荐配色中选择／我指定颜色。推荐选项提供原色、柔和强调、浓郁强调三种，按钮显示背景/正文/强调色色值，本地向导显示色块。指定颜色支持中文名、#RGB/#RRGGBB 和取色器，一轮最多三个角色；已有颜色不再问。

`new.py` 将选定颜色记录到视觉方案的 `palette` 并内联到项目 CSS，T3 的材质和粒子继续读取同一 CSS 变量。改颜色后重确认方案；预设源文件、字体定义和等级不变。自定义风格的预设色仅为极简占位，仍需结合真实参考确认完整方案。

## 素材与内容

默认 SVG/CSS 程序化；Canvas 动态纹理和粒子只用于 T3。按原七套风格选手法，极简/学术保持留白与发丝线。装饰 aria-hidden、pointer-events:none，窄屏隐藏大装饰，正文和教学图示不可因此丢失。

内置 imagegen 须用户明确授权及注明背景/贴图/装饰范围，完整视觉方案批准后才执行；不要求用户 API key。单张原图及其 base64 编码内容均 <500000 字节，内联并说明 AI 来源、生成工具和替换 data URL 方式；网络真实图片需核验许可。

用户已授权搜索时不再要求材料。优先机构、大学、论文、教材等一手来源，关键事实给可点击依据；设想/示例不冒充真实成果。待用户提供材料时不擅自以搜索替代。无法联网或核验时说明限制，完成已核实部分，只问必要缺口。
