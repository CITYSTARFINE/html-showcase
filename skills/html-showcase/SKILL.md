# HTML 展示页

先阅读 [README.md](README.md)。用户首次提出制作需求后，立即执行其中的“首次需求选项”，主动询问未明确的视觉方向、美术完成度、技术等级、展示交互和内容来源，再规划、构建、截图验收、交付。

- 用户亲选等级，不得因风格升级技术。用户说“随便”时明确告知：课堂默认 T1，产品默认 T2；其他用途继续询问等级。
- T3 动工前必须获得明确确认。用户已明确确认的授权无需重复询问。创建或维护这个通用脚手架本身不代表选择 T3 展示项目。
- 在首次选项流程中让用户选择内容获取方式：自行提供材料、授权搜索并生成、或两者结合；用户已明确选择时无需重复询问。按 README 的“内容获取方式”执行。授权搜索后不强制用户提供材料；仍不得虚构事实、数据、引用或产品卖点。
- 使用 `new.py` 交互生成；模板与公共资源都相对本技能目录解析。生成后只修改项目的 `index.html`，保持最终单文件交付。
- T1 使用 `templates/t1.html`，T2 使用 `templates/t2.html`，T3 使用 `templates/t3.html` 和 `js/t3-base.js`。等级交互和场景硬性规范见 README；风格只来自 `styles/presets.css` 的变量及装饰。
- 在浏览器验证桌面与窄屏、键盘、对应等级交互以及减少动态效果设置；T3 额外验证导览退出、相机飞行锁定、页面隐藏暂停、CDN/WebGL 失败摘要。截图检查遮挡、溢出、可读性。60fps 是需要实测的目标，不是保证。
- 交付 `index.html`，说明 T3 固定版本 CDN 的联网条件与静态降级结果；如不能完成截图或性能验收，明确说明限制。

## 装饰素材生成规范

展示页的装饰类视觉素材（背景纹理、分隔线、插图、hero 配图）默认程序化生成，不调用外部生图 API。

- 使用内联 SVG 制作图案、插图、印章、噪点滤镜；使用 CSS 制作渐变、辉光、扫描线；Canvas 粒子和动态纹理仅用于 T3，并复用其单一渲染循环。静态 SVG/CSS 装饰不改变等级，不得向 T1 加入滚动叙事或向 T1/T2 加入三维、Canvas 动态纹理。
- 按风格选择手法：国风＝水墨渐变、印章 SVG、细框线；科技＝网格线、辉光边、等宽数据标签；赛博朋克＝霓虹渐变、扫描线、噪点 overlay；扁平插画＝几何图形、柔和阴影；暗黑＝暗角、细金线、克制辉光；极简/学术＝留白、发丝线分隔，不添加其他装饰。
- 装饰不得干扰正文可读性。纯装饰 SVG 标记 aria-hidden="true"，装饰层 pointer-events:none；正文保持足够对比度。窄屏隐藏大插图及复杂装饰层，保留底色；在截图验收中检查。具有教学信息的图示属于内容，必须依据用户材料或经核验的可靠来源制作，不可当作装饰隐藏或编造。
- 例外：仅当用户明确要求写实/摄影级配图，并能提供可用的生图 API key 时，才可使用 AI 生图。通过安全的密钥配置使用，绝不把 key 写进 HTML、技能或交付文件。
- 例外图片转为 base64 内联进最终 HTML。每张原始图片及 base64 编码内容均须小于 500KB（保守按 500000 字节检查）；超限先缩放或压缩，再核验清晰度。交付时注明图片来源/生成工具与替换方式；替换对应 img 的 data URL，并保留 alt 文本及尺寸约束。
## 首次需求选项

- 第一次收到制作请求时，先整理用户已明确的用途、主题、风格、等级与内容来源，简短复述，然后主动询问尚缺的视觉和交互偏好。不得只因有主题和等级就直接构建；“直接开始”不自动代表用户授权随意选择所有视觉细节。用户明确授权“视觉交互你定/全部随便”时才可采用合理选择并告知。
- 优先调用当前环境可用的原生选项工具，让用户直接点击：支持时使用 `request_user_input_async`；`request_user_input` 仅在当前模式允许且问题适合其约束时使用。每轮最多三问，同轮合并；不要把工具调用写成普通文字。工具未提供时才使用简短编号选项，不声称普通 Markdown 是可点击按钮，不为收集偏好额外创建网页。
- 用户已经明确选择 T1 或学术风格时保留，不重复要求选择同一项目；仍须询问其未表达的具体美术方向/完成度和展示交互。可将已知项写入问题，例如“保持 T1＋学术，你偏好哪种版式完成度？”
- 第一轮优先问视觉方向/完成度、未定的技术等级、展示交互；已有选择就用空出的问额补内容来源、受众与时长。其余必要项在下一轮补齐。已有授权与偏好在后续对话持续有效，不每轮重问。
- 等待必需的选择再构建对应视觉/交互；等待期间可做已授权的资料搜索与内容规划。按钮预选不是用户已选择，超时也不是确认。若可选问题没有回复，可采用明确告知的合理假设；用户亲选等级及 T3 确认不能靠假设取得。
- 选完后给出具体视觉摘要：配色、字体、版式、内容图示、交互、受众、时长与来源方式。选择本身已足以授权这些实现，无需增加重复确认；T3 动工前的明确确认仍必须取得。
