# 学术用途的逻辑与图示要求

本节补充学术风格的内容组织，不改变七套风格的配色、字体、质感预设，也不改变 T1/T2/T3。触发条件是**学术用途**：论文答辩、课程汇报、课堂教学、学术展示等；即使选科技、国风等配色也执行。学术预设同样执行；原创纯视觉演示无需虚构论点。

## 规划：先提炼一条逻辑主线

在提出视觉方向前，用一句话说清“这篇的核心论点／逻辑主线是什么”。基于已提供或已核验内容提炼，不凭标题编造结论。

建立“章节 → 对主线的贡献”清单：每章回答哪个问题、提供哪项证据或推进哪一步。所有章节挂在主线上；跑偏、不能说明贡献的章节直接从方案删除，不用装饰性故事凑页。已给定事实、引用和不可改文案不改写，不把原始材料文件删除；有范围冲突在方案说明。

2–3 个视觉方向不仅比构图，还说明怎样把同一逻辑主线呈现得更清楚。用户选定方向后，在完整视觉方案列出主线、章节贡献、关系图示清单与过渡句，和构图、关键画面、素材计划一起确认。

## 视觉方案与制作：关系必须图示化

凡概念之间出现因果、对比、递进、总分、并列关系，必须以图示表达，不许只堆文字段落：

| 关系 | 合适的图示 |
| --- | --- |
| 因果 | 带方向和条件标注的流程图/因果图 |
| 对比 | 对比表/并排对照图，比较维度一致 |
| 递进 | 步骤流程图；有真实时间顺序时使用时间线 |
| 总分 | 层级图/树图，分支与总论点对应 |
| 并列 | 分组关系图/对比表，明确共同上位概念 |

每项记录源概念、目标概念、关系、图示类型、放置章节及证据来源。根据核实内容选择图示，不为了“图示化”捏造因果或把非时间关系画成时间线。图示是教学内容，不属于可隐藏的装饰；窄屏保留标签、图例和逻辑，允许纵向重排/分组。

T1 用语义 HTML 表格、内联 SVG/CSS；T2 可在不影响完整阅读的前提下显现图示；T3 的关系说明仍优先可读的 2D UI，遵守飞行淡出/到达显现。无需为图示升级等级。AI 装饰不能作为论点证据或代替可核验的关系图。

## 章节过渡显性化

每章开头一句话点明承上启下：“上一章讲了 X，这一章讲 Y，因为 Z”。可以自然改写句式，但必须保留前章结论、当前问题及转入理由。首章用“先提出核心问题 X，再沿 Y 展开，因为 Z”承接标题/引言，不虚构上一章。

制作时将过渡句放在可读正文/字幕中，不只藏于注释或方案文档。验收逐章核对过渡是否与实际内容和主线一致。

## 附加验收与返工条件

- 检查主线一句话、全部章节的贡献、所有已识别关系的图示、每章开头过渡句；缺任何一项、偏题章节保留、图示关系错误或只堆文字均返工。
- **找一位未读过材料的真人看完整页面，不预先提示主线，再请其复述核心论点和章节推进关系。说不出逻辑主线 → 返工。** 记录测试日期、使用版本、原话与判断依据，不强制记录个人身份。
- 尚无真人参与时结论为“小修”，清单写“待陌生读者复述测试”；不能由作者、Codex、另一个 AI 的复述替代真人测试，不能伪造受试者反馈。
- 本条与 tiers.md 同时执行，结论仍仅“通过／小修／返工”。
