# 分档视觉方案与验收

等级与风格独立；视觉方案与验收须遵守所选等级的能力边界和七套风格预设。

## 各档共用：方向选择 → 完整方案 → 用户确认

先给 2–3 个构图方向供选择，每个有名称、一句话描述、关键画面差异、适用场景。不得直接提交最终方案。用户实际选定或要求修改后才细化；重新修改方向须再次选定。

对标参考和效果依据仅允许真实照片、真实画作、真实项目截图。打开来源核验，记录作者/项目、出处链接或路径、对应依据与核验说明；来源含糊或真实性不明不作证据。没有合适参考时写“暂无对标”，说明效果尚无对标，不以 AI 图补位。AI 只能在最终素材制作阶段、明确授权范围内使用。

完整方案必须同时提供：

1. 每一屏的一句话构图草案：前景／中景／背景，正文与交互焦点位置；写清窄屏调整。
2. 3–5 个关键画面：每个目标效果、与真实参考的对应（无参考写暂无对标）、可验收特征。
3. 素材计划：逐项名称、谁制作、方法（SVG/CSS/Canvas 程序化、经授权 AI、用户素材或授权真实图片）、尺寸（像素或视口/矢量约束）、来源与许可/生成说明；无需素材时写空清单及理由，不能漏交。

三项齐备及本档追加项完成，才请用户通过选项确认或提出修改。记录选择依据、确认答复和需求/方案摘要；方案变化后旧确认失效。

## T1 轻量

**技术与交互**：语义化 HTML、CSS 入场动画、零依赖；锚点点击、方向键和空格切章；CSS hover 状态。不得加入滚动叙事、视差或三维。

**视觉方案要求**：完成共用三项；每屏包含标题、正文、图解或留白位置，描述 CSS 入场与 hover 状态、阅读顺序及桌面/窄屏排布。选择方向只改变设计，不越级。学术/极简保留留白与发丝线，不添无意义装饰。

**验收项**：桌面 1440×900、窄屏 390×844（用户指定设备优先）；逐章截图，文字完整、无横向溢出；锚点、方向键、空格和 hover 可用，输入框内按键不误切章；减少动态效果后内容仍可读；断网无外部运行依赖；配色、字体、构图及关键画面符合已确认方案。

**返工触发条件**：正文/关键按钮被遮挡；横向溢出影响阅读；正文对比度低于 4.5:1（大字低于 3:1）；配色与需求或批准方向不符；点击/键盘无法切章；加入超档技术或运行依赖；未经批准改变文案事实或把素材模板占位交为成品。

## T2 精美

**技术与交互**：IntersectionObserver 滚动显现/转场、视差层、卡片按钮 hover 微交互、平滑导航、阅读进度；每章一个 hero 时刻。最多一个 CDN 动画库，本模板不使用。不得加入 three.js。

**视觉方案要求**：完成共用三项；逐屏注明 hero 焦点、前中后景视差层、显现时机、段间转场、滚动与导航关系及窄屏降级。方向比较须说明 hero 与叙事节奏差异，不因精美引入三维。

**验收项**：共用桌面/窄屏阅读检查；逐章验证滚动进入/离开、视差、卡片/按钮 hover、导航平滑滚动、进度从顶部至底部范围正确，每章都有 hero；减少动态效果时显示全部正文并停止装饰视差；无输入方式陷阱；检查外部库数量和固定加载来源；逐关键画面与批准方案比对。

**返工触发条件**：T1 的遮挡、溢出、对比度、配色问题；章节因滚动显现错误一直不可见；导航跳错章、进度失真或关键热点无效；任一章缺 hero；减少动态效果后隐藏正文；three.js 或超过一个 CDN 动画库；叙事/素材与批准方案不符。

## T3 极致

**技术与交互**：importmap 引入 three.js，锁定 `0.170.0`，禁止 latest；1800 个粒子（必须小于 20000）、单 rAF 循环，目标 60fps，需目标设备实测。

**视觉方案要求**：完成共用三项并追加：

- 镜头路径：每章起止位置/目标、前中远景关系、飞行轨迹、停留时长、字幕焦点及探索范围；章节飞行 1.2–1.8 秒（基础模板 1.5 秒），飞行中禁用用户控制。注明导览被输入打断后如何恢复探索。
- 光照方案：半球/主方向/1–2 rim 的方向、颜色、强度、投影对象，雾色/范围、曝光、材质响应；说明主视觉焦点与近实远虚。基础模板 antialias、pixelRatio≤2、相机 45–60°保持。
- 后处理清单：逐项目的、参数范围、性能预算、窄屏降级；不用时明确“无后处理”。若额外反射/阴影，列贴图大小及优化预算，不把昂贵后处理当必选技术。

**验收项**：桌面/窄屏截图；检查 raycast pointermove 节流、悬停 emissive/1.05 倍缩放/标签、点击状态变化、拖拽/缩放与极角钳制；相机路点、字幕、任意用户输入退出导览，飞行锁定和 overlay 淡出淡入；wrapper pointer-events:none、按钮 auto；页面隐藏停止渲染，恢复仍单 rAF；WebGL2 不支持、CDN 失败、上下文丢失均出现带样式标题要点，无白屏、无卡住加载器。测 pixelRatio、粒子数与版本锁定。

**帧率测量口径**：目标仍 60fps。记录设备/GPU、浏览器、视口、DPR、功耗条件；正常加载后选三个代表机位，每处可见状态连续采样 10 秒，记录平均 fps 和最大卡顿及交互情况，排除加载/后台暂停。任一平均 <50fps 为明显不足并返工；50–59fps 为小修，列优化项后复测；≥60fps 还需其余项目通过。没有实测证据只能小修并列缺测清单，不能宣称 60fps 已达成。用户更严格标准另行记录，不自动降技术等级。

**返工触发条件**：共同的阅读/配色/方案偏离问题；任一代表机位平均 <50fps；关键交互失效、导览无法被输入退出、飞行仍可操控、多个 rAF、后台持续渲染；粒子≥20000、DPR>2、浮动版本；任一失败条件白屏或卡加载器；缺必要场景雾/灯光/相机规格；未授权 AI 素材或伪造性能数据。

## 统一结论（只允许以下三档）

- **通过**：所有本档必验项有证据、无返工条件；记录截图、交互、异常/性能证据和实际环境。
- **小修**：不触发返工的局部间距、按钮状态等问题，或有未验证项；逐条列“问题 → 修复/补测 → 复测方式”。不能写“基本通过”，不能隐去未测。
- **返工**：命中任一返工条件，列原因、对应画面/步骤/测量证据与修复方向，修复后复测再下结论。

任何等级：跳过视觉方向选择或完整方案确认、拿 AI 图当效果证据、编造事实/来源、越过素材授权均返工。各项机械检查不替代画面审阅；对照批准方案作判定，不使用“好看/高级/差点意思”作为独立验收标准。

## 学术用途附加验收（所有等级）

按 [styles.md](styles.md) 执行一句主线、每章贡献、关系图示与开头过渡句检查；任何缺失或偏题章节未删除均返工。找未读过内容的真人看完复述：说不出逻辑主线 → 返工，记录原话；未做此项测试 → 小修并列待测，不得用 AI 复述冒充真人验收。用途触发，与所选配色无关。
